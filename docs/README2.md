# REX Health & Sports Community Bot

## Обзор проекта
**REX Health & Sports Community** — это многофункциональный Telegram-бот, созданный для поддержки активного образа жизни. Бот объединяет в себе функции персонального диетолога, тренера и платформу для поиска спортивных партнеров (дейтинг).

## Основные возможности
- 🥗 **Диетолог**: Персонализированные рекомендации по питанию на основе AI.
- 🏋️ **Тренер**: Планы тренировок и советы по фитнесу.
- 🤝 **Дейтинг**: Поиск партнеров для совместных занятий спортом.
- 📜 **Астрология**: Генерация натальных карт и гороскопов.
- 🎫 **Система QR-кодов**: Активация доступа и бонусов через сканирование кодов с продукции REX.
- 📊 **Мониторинг**: Полный контроль состояния системы через Grafana и Prometheus.
