# Интеграции

## 🤖 Telegram Bot API
Используется через библиотеку `aiogram`.
- **Long Polling**: Используется для получения обновлений (процесс `bot_polling`).
- **Proxy**: Все запросы к Telegram API идут через Squid Proxy (настраивается в `Settings`).

## 🧠 AI (OpenAI / Groq)
Основной мозг бота для режимов коуча.
- **Provider**: OpenAI (модель `gpt-4o-mini`) или Groq (модель `llama-3.3`).
- **Context**: Для каждого запроса формируется System Prompt, в который подставляются данные из анкет пользователя.
- **Async**: Запросы выполняются асинхронно в `worker_ai`, чтобы не блокировать интерфейс бота.

## 📊 Google Sheets
Используется для хранения конфигураций или выгрузки данных.
- **Library**: `gspread-asyncio`.
- **Auth**: Через файл сервисного аккаунта `google_key.json`.
- **Usage**: Бот может считывать тексты опросов или настройки бонусов напрямую из таблиц, что позволяет менять логику без перезагрузки кода.

## 📈 Monitoring Stack
- **Prometheus**: Собирает метрики из Python-кода (через `prometheus_client`). Основные метрики: количество сообщений, ошибки LLM, время генерации ответа.
- **Loki**: Собирает структурированные логи от `structlog`. Позволяет быстро находить ошибки в конкретных сессиях пользователей.
- **RabbitMQ**: Служит связующим звеном, позволяя масштабировать количество AI воркеров при росте нагрузки.
