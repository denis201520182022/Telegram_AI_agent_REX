# User Flow (Путь пользователя)

Бот реализует сложную воронку взаимодействия, начиная от активации доступа до ежедневного использования коучинговых функций.

## 1. Вход и Авторизация
1. Пользователь запускает бота (`/start`).
2. **Проверка доступа**: Бот проверяет наличие активной подписки в базе данных.
3. **QR-активация**: 
   - Если доступа нет, бот предлагает отсканировать QR-код с продукции REX.
   - Пользователь переходит по ссылке вида `t.me/RexBot?start=hash`.
   - Бот начисляет 5 дней подписки и бонусы (например, кредиты на натальную карту).

## 2. Анкетирование (Onboarding)
Перед использованием основных функций пользователь должен заполнить анкеты:
- **Опрос диетолога**: Цели, текущий вес, предпочтения в еде.
- **Опрос тренера**: Уровень подготовки, доступный инвентарь.
- **Опрос дейтинга**: Город, пол, интересы, кого ищет.

Анкеты реализованы через FSM (Finite State Machine) и сохраняются в таблицу `user_surveys`.

## 3. Режимы работы

### 🥗 Коуч-Диетолог
- Пользователь задает вопросы по питанию.
- Бот использует AI для генерации ответов, учитывая данные из анкеты диетолога (промпт формируется с учетом контекста пользователя).

### 🏋️ Коуч-Тренер
- Запросы на составление программ тренировок.
- AI учитывает уровень подготовки и цели пользователя из анкеты тренера.

### 🤝 Спортивный Дейтинг
- **Ежедневный подбор**: Раз в сутки планировщик запускает алгоритм `run_daily_matching`.
- Алгоритм ищет пересечения по: Городу, Возрасту, Полу и Видам спорта.
- Пользователь получает уведомление с анкетой и фото потенциального партнера.
- Варианты действий: Лайк (уведомляет второго пользователя) или Следующий.

### 🌟 Астрология и Бонусы
- За каждые 5 активированных QR-кодов пользователь получает 1 "кредит" на генерацию детальной натальной карты.
- Ежедневные гороскопы доступны всем пользователям с активной подпиской.

## 4. Управление профилем
Через главное меню пользователь может:
- Обновить свои анкетные данные.
- Посмотреть статистику активаций.
- Управлять уведомлениями.
