# Структура модулей

### Корень проекта
- `main.py`: Точка входа для запуска бота (в упрощенном режиме) или тестирования.
- `config.py`: Загрузка конфигурации.
- `docker-compose.yml`: Описание всех сервисов системы.
- `Dockerfile`: Инструкция по сборке образа приложения.
- `alembic.ini`: Настройки миграций.

### `src/` — Исходный код
- `bot/`: Основная логика Telegram-бота.
  - `handlers/`: Обработчики команд и сообщений (меню, дейтинг, коуч, опросы).
  - `keyboards/`: Генераторы инлайн и реплай клавиатур.
  - `middlewares/`: Прослойки (проверка подписки, логирование активности).
  - `main.py`: Основной файл запуска процесса бота.
- `database/`: Работа с данными.
  - `models.py`: Описание таблиц SQLAlchemy.
  - `session.py`: Настройка асинхронного подключения и сессий.
  - `connection.py`: Базовые функции подключения.
- `services/`: Внешние интеграции и бизнес-логика.
  - `llm.py`: Клиент для работы с AI.
  - `matching.py`: Алгоритм подбора пар для дейтинга.
  - `rabbit.py`: Утилиты для работы с очередями.
  - `redis.py`: Клиент Redis.
  - `sheets.py`: Взаимодействие с Google Sheets.
- `workers/`: Фоновые процессы.
  - `ai_worker.py`: Обработка нейросетевых запросов.
  - `sender_worker.py`: Отправка сообщений пользователям.
  - `scheduler.py`: Запуск периодических задач.
- `utils/`: Вспомогательные инструменты.
  - `logger.py`: Настройка структурированного логирования.
  - `metrics.py`: Определение метрик Prometheus.
  - `alerting.py`: Система уведомлений о критических ошибках.
  - `text.py`: Обработка и форматирование текстов.
- `scripts/`: Скрипты для обслуживания (генерация QR, инициализация конфигов).

### `migrations/`
Файлы миграций Alembic для управления структурой базы данных.

### `monitoring/`
Конфигурационные файлы для Prometheus, Loki и Promtail.
