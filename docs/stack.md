# Технологический стек

Проект использует современный стек технологий на языке Python, ориентированный на высокую производительность и масштабируемость.

## Core (Ядро)
- **Python 3.12+**: Основной язык разработки.
- **aiogram 3.x**: Асинхронный фреймворк для Telegram-бота.
- **Pydantic V2**: Валидация данных и управление настройками.

## Database & Storage (Хранение данных)
- **PostgreSQL 15**: Реляционная база данных.
- **SQLAlchemy 2.0**: Асинхронная ORM.
- **Alembic**: Управление миграциями базы данных.
- **PgBouncer**: Легковесный пул соединений.
- **Redis 7**: Быстрое хранилище "ключ-значение" для FSM и кэша.

## Message Broker (Очереди)
- **RabbitMQ**: Брокер сообщений для асинхронных задач.
- **aio-pika**: Асинхронная библиотека для работы с RabbitMQ.

## AI & Integrations (ИИ и интеграции)
- **OpenAI / Groq API**: Модели GPT-4o-mini и Llama 3.3 для чатов с коучем.
- **gspread-asyncio**: Асинхронная работа с Google Sheets.
- **Google Auth**: Авторизация в сервисах Google.

## DevOps & Observability (Мониторинг и деплой)
- **Docker & Docker Compose**: Контейнеризация всех компонентов системы.
- **Prometheus**: Сбор метрик приложения и инфраструктуры.
- **Grafana**: Создание дашбордов для мониторинга.
- **Loki & Promtail**: Сбор и агрегация логов.
- **cAdvisor**: Мониторинг ресурсов контейнеров.
- **structlog**: Структурированное логирование.

## Utilities (Утилиты)
- **APScheduler**: Планировщик задач.
- **httpx**: Асинхронный HTTP-клиент.
- **python-dotenv**: Работа с переменными окружения.
